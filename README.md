# analysis_HVR
## Стартап датчики контроля состояния спортсмена

Приложение анализирует записи ЭКГ (вариабельность сердечного ритма, ВСР) спортсменов, снятые нагрудным пульсометром Polar H10. Показывает тепловые карты, графики метрик, журнал записей, позволяет добавлять комментарии к метрикам.

### Возможности

- **Графики метрик**: TP, Стресс, ЧСС и RMSSD.
  - Колесо мыши — вертикальная прокрутка списка графиков.
  - ЛКМ + колесо — изменение масштаба (зум по времени).
  - ЛКМ перетаскивание — перемещение по времени.
  - ПКМ — сброс масштаба.
- **Настройки метрик** (кнопка «⚙ Настройки»): выбрать, какие метрики показывать, и их порядок.
- **Комментарии к метрикам**: двойной клик по столбику открывает комментарий для даты; жёлтый треугольник и текст в подсказке.
- **Журнал ЭКГ**: записи атлета (экспорт, удаление, биометрическая схожесть); сортировка — кликом по заголовку столбца.
- **Тепловые карты**: годовая и недельная плотность записей.
- **Инструкция**: F1 — окно помощи со скриншотами.

Для запуска проекта нужны внешние библиотеки. Всё остальное (os, sys, sqlite3, datetime, uuid, random, math) входит в стандартную библиотеку Python.

| Библиотека | Для чего |
| --- | --- |
| customtkinter | GUI приложения (app.py, dialogs) |
| matplotlib | Графики метрик |
| tkcalendar | Виджет календаря для ввода даты рождения |
| sqlalchemy | ORM для работы с БД (models.py) |
| pyyaml | Чтение config.yaml и ecg_profiles.yaml |
| numpy | Анализ сигнала ЭКГ и RR-интервалов |
| scipy | Фильтрация сигнала, спектральный анализ, биометрия |
| pillow | Отображение скриншотов в инструкции (F1) |
| dtaidistance | DTW-сравнение форм сигнала для биометрии |

## Установка

Рекомендуемый способ — через `requirements.txt` с **зафиксированными версиями**.
Это важно: golden-тесты (`tests/test_reference_ecg.py`, `tests/test_bio_ecg_reference.py`)
сверяют расчёт метрик с эталонными значениями, а они зависят от версий
`numpy`/`scipy`. Установка других версий приводит к расхождению чисел
с плавающей точкой и ложным падениям тестов.

```bash
pip install -r requirements.txt
```

Файл `requirements.txt` лежит в корне проекта:

```txt
customtkinter==6.0.0
matplotlib==3.11.1
tkcalendar==1.5.0
sqlalchemy==2.0.51
pyyaml==6.0.3
numpy==2.5.1
scipy==1.18.0
pillow==12.3.0
dtaidistance==2.5.0
```

Одной командой (если нужен минимальный набор без фиксации версий):

```bash
pip install customtkinter matplotlib tkcalendar sqlalchemy pyyaml numpy scipy pillow dtaidistance
```

### Проверка установки
```bash
python -c "import customtkinter, matplotlib, tkcalendar, sqlalchemy, yaml, numpy, scipy, PIL, dtaidistance; print('✅ Все библиотеки установлены')"
```

Если всё ок — можно запускать:

```bash
cd src/scripts
python prepare_database.py
cd ..
python app.py
```

## Миграция старой базы данных

Старая схема БД (например `src/data/__ecg.db`) может не открываться новой
версией: в `ecg_records` не хватает колонок `tp`, `updated_at`, `device_id`,
а `athletes.birth_date` почти всегда содержит фиктивную дату `2005-01-01`
(значение по умолчанию старого диалога).

Новая версия чинит минимальную схему автоматически при запуске
(`models._migrate` добавляет недостающие колонки и приборы). Просто откройте
базу один раз — приложение стартует без сбоя.

Если нужно перенести в заведомо новую базу и пересчитать метрики по ЭКГ
(минимальный набор — фамилия, имя и сырая запись), используйте скрипт:

```bash
cd src/scripts
python migrate_legacy_db.py ..\data\__ecg.db   # → data\__ecg_migrated.db
```

Скрипт переносит фамилию/имя/ЭКГ, пересчитывает ВРС-метрики по записи,
проставляет прибор по `polar_id` и очищает фиктивные даты рождения.
