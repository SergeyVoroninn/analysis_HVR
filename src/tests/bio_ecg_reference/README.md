# bio_ecg_reference — эталонный набор для теста определения атлета по ЭКГ

Регрессионный набор данных для теста `tests/test_bio_ecg_reference.py`.
Проверяет модуль `src/ecg_biometrics.py` (биометрическое определение атлета
по ЭКГ).

## Зачем

Есть 4 атлета (данные `raw_data/sambo`): `andrey`, `filipp`, `konstantin`,
`trofim`. Записи в исходнике частично продублированы и перемешаны («бардак»).

Тест проверяет гипотезу:
- из записей атлета, выбранного **эталоном** (у кого больше всего уникальных
  записей — это `filipp`), строится биометрический шаблон;
- берётся по ОДНОЙ записи каждого атлета и сравнивается с шаблоном;
- запись **эталона** должна дать **наибольшее совпадение** (минимальное
  расстояние).

Результаты сравнения сохраняются в `results_golden.json`. Если текущие
результаты изменятся относительно golden — тест падает и подсвечивает, что
изменились **настройки** (класс `ECGConfig`) или **алгоритм**.

## Состав папки

| Путь                  | Что это                                                          |
|-----------------------|------------------------------------------------------------------|
| `template/`           | Записи эталона (`filipp`), из которых тест строит шаблон         |
| `probes/`             | По одной записи каждого атлета для сравнения с шаблоном          |
| `manifest.json`       | Метаданные: эталон, список записей шаблона, маппинг probes→атлет |
| `results_golden.json` | Сохранённые эталонные результаты сравнения (golden)              |

## Как генерировалось

Набор собирается скриптом `src/scripts/build_bio_ecg_reference.py`:
дедуплицирует записи по md5 внутри и между папками атлетов, выбирает эталон,
копирует `filipp`-записи в `template/` (исключая пробу-holdout) и по одной
пробе каждого атлета в `probes/`.

Пересобрать набор:

```bash
python src/scripts/build_bio_ecg_reference.py
```

После пересборки (если изменился состав данных) обновить golden:

```bash
cd src
$env:UPDATE_GOLDEN="1"
python -m pytest tests/test_bio_ecg_reference.py
```

## Запуск теста

```bash
cd src
python -m pytest tests/test_bio_ecg_reference.py -v
```

## Как тест ловит изменения настроек/алгоритма

Тест `test_results_unchanged_since_golden` каждый прогон заново:

1. Строит шаблон эталона через реальную функцию `create_and_save_template`
   (во временной БД).
2. Сравнивает каждую пробу через реальную `check_ownership_with_saved_template`.
3. Сверяет get-результаты с `results_golden.json` с допуском `1e-6`.

Если изменить пороги/веса в `ecg_biometrics.ECGConfig` или поправить алгоритм —
расстояния/вероятности изменятся, тест упадёт с явным сообщением.

Если подменят сами записи в `bio_ecg_reference` — это зафиксирует контрольный
ключ `dataset_key` (хэши шаблона и проб) в golden-файле.
